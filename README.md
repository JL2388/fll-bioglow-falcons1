# fll-bioglow-falcons1
First Lego League code for the Bioglow 2026 Season for Falcons1.

Tree Code
Control each motor using the levers. 
Do NOT put both of them in the same direction if wanting to turn both at the same time.
Push both in the same direction to go to set positions.
Left Lever = Left Motor
Right Lever = Right Motor
Up = Clockwise
Down = Anti-Clockwise

Colour Sensor
Blue and Red set to set amount of launching.
